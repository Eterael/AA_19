EPITOPE A03:01 HELD-OUT TRAINING RUN: FILE DESCRIPTION
======================================================

Purpose
-------
This is the network-training run for the new epitope table data.

The new XLSX epitope export is treated as an all-binder positive set for
HLA-A03:01. Because the XLSX does not contain non-binders, negatives are added
from hla_only.txt using unique label-0 9-mer peptides. Same-allele HLA-A03:01
negatives are used first, then the remaining negative slots are filled with
unique label-0 peptides from other alleles.

The combined labeled dataset is then split with the same held-out-AA logic:
  Train/CV peptides: no held-out amino acid anywhere.
  Evaluation peptides: contain the held-out amino acid.

Default split
-------------
Allele: HLA-A03:01
Held-out amino acid: W
Positive source: canonical 9-mers from epitope_table_export_1779969300.xlsx
Negative source: unique label-0 9-mers from hla_only.txt
Negative sampling: 1:1 positive/negative ratio in train/CV and evaluation

Run order
---------
1. Run Epitope_Table_Heldout_Run.ipynb if the XLSX-derived canonical epitope
   CSVs are missing or stale.

2. Run Epitope_A0301_Heldout_Training_Run.ipynb from top to bottom.

3. In that notebook, Step 1 prepares and checks the combined positive/negative
   split. Step 2 trains AE, one-hot, and BLOSUM62 models. Step 3 displays the
   summary CSVs after training.

4. Run Epitope_A0301_Heldout_Analysis.ipynb to generate and view sequence
   logos, ROC curves, confusion matrices, top-prediction slice analyses, and
   detailed performance tables.

Requirements for Step 2
-----------------------
The full network-training cell needs a Jupyter kernel with torch and
torchvision installed. The AE encoder also needs:
  peptide_autoencoder_v3_512.pth
  peptide_rotamers/

Generated files
---------------
epitope_a0301_heldout_training_run.py
  Script version of the epitope A03:01 training run.

Epitope_A0301_Heldout_Training_Run.ipynb
  Notebook entry point for preparing the combined labeled split, training the
  networks, and reporting the generated summaries.

  Counts for positive and negative sources and selected split support.

epitope_a0301_heldout_results/Epitope_A0301_19AA_Split_Candidates.csv

  fold assignment. Peptides are unique.

epitope_a0301_heldout_results/*Heldout_Evaluation_9mers_Labeled.csv
  Combined held-out evaluation peptides with labels, source fields, and source
  alleles. Peptides are unique and do not overlap the train/CV file.

  Written after Step 2 training finishes. Contains cross-validation metrics.

epitope_a0301_heldout_results/*Heldout_Evaluation_Summary.csv
  Written after Step 2 training finishes. Contains held-out evaluation metrics.

Epitope_A0301_Heldout_Analysis.ipynb
  Analysis notebook for the trained run. It creates the analysis_* directory
  with SVG figures and CSV summaries.
