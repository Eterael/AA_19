EPITOPE TABLE 19-AA HELD-OUT PREPARATION: FILE DESCRIPTION
===========================================================

Purpose
-------
This workflow prepares the new IEDB epitope table XLSX as an epitope-only
held-out preparation run. It keeps canonical unmodified 9-mer epitopes,
then creates a train/CV set with one amino acid absent and an evaluation set
where that amino acid is present.

The epitopes in this workbook are treated as binders for HLA-A03:01. The
workbook does not include non-binders, so the supervised training run is
handled separately in Epitope_A0301_Heldout_Training_Run.ipynb. That
training notebook introduces unique label-0 peptides from hla_only.txt as
non-binders, using same-allele negatives first and other-allele negatives
to make a 1:1 split.

Input file
----------
epitope_table_export_1779969300.xlsx
  IEDB epitope table export. The workflow reads Sheet1 and uses the epitope
  fields from the first two header rows. The epitope sequence is the Epitope
  Name column.

Filtering decisions
-------------------
Rows are retained only if all of the following are true:
  Object Type is blank or Linear peptide.
  Epitope Name is present.
  Modified Residue(s) and Modifications are both empty.
  The cleaned epitope sequence contains only ACDEFGHIKLMNPQRSTVWY.
  The cleaned epitope sequence is exactly 9 residues long.

The non-canonical sequence rule removes entries with +, X, B, Z, J,
brackets, gaps, or other uncertainty/modification notation in the sequence.
Rows that carry modification/uncertainty annotations in the workbook fields
are excluded before the sequence regex check, so exclusion counts are not
double-counted.

-----------------

acids so a different held-out amino acid can be selected without changing
the filtering logic.

Generated files

  Notebook with visible saved summary, candidate table, split preview, and

  Downstream network-training notebook. It treats these canonical epitopes as
  HLA-A03:01 binders and adds unique label-0 peptides from hla_only.txt as
  non-binders. Same-allele negatives are used first, then other alleles fill
  the 1:1 split.
